# V5.2 Initial Hybrid Pipeline Archive

This folder preserves the first compact working version of the ElectroMacroDiff hybrid pipeline.

What V5.2 contributed:

- modular Python pipeline code in `EMD_v5_2_original_code/emd_pipeline/`
- notebook-style execution steps in `EMD_v5_2_original_code/notebooks/`
- first SE(3) flow model implementation draft
- candidate generation, docking, ADMET, ranking, and dashboard modules
- V5.2 master execution blueprint and SE(3) addendum in `planning_documents/`

V5.2 is important for reviewer explanation because it shows the project did not start directly at V5.5. It began as a smaller hybrid workflow and then gained model-guided generation, pocket-electronic scoring, and V5.5 pocket-conditioned decision models.
