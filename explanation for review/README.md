# ElectroMacroDiff V5.5 Explanation Bundle

This folder collects Markdown explanations and visual assets from the repository into one place for project discussions, presentations, evaluation meetings, and future continuation work.

It is not a separate pipeline implementation. The active code and real data remain in the repository root folders:

- `src/` and `scripts/` for implementation
- `04_models_checkpoints/` for trained project checkpoints
- `05_generated_candidates/` for generated V5.5 molecules and attempt logs
- `06_docking/` and `08_final_ranking/` for docking, scoring, and ranking outputs
- `interface/` for the interactive dashboard
- `versions/` for earlier project evolution evidence

Contents in this bundle:

- `docs/` - copied Markdown documentation about architecture, datasets, models, metrics, and claim boundaries
- `reports/` - copied report Markdown files and project-generated visual assets
- `submission_artifacts_2026-05-28/` - copied presentation/document support files and diagrams

All included files are derived from tracked project outputs. No experimental wet-lab validation is implied.
